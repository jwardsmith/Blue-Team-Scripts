# Slow Checker

1. Reboot - clear memory
2. Task Manager - high memory or CPU
3. Task Manager - weird processes
4. File Explorer - storage space
5. Task Manager -> Startup - startup apps and background processes
6. Task Manager -> Performance -> Disk - check if at 100%
7. Disk Cleanup - cleanmgr
8. Drive Health - chkdsk C: /f
9. Windows Updates
10. Device Manager Driver Issues
11. Windows AV Security Scan
12. Scheduled Tasks
13. Browser Extensions
14. System File Checker - sfc /scannow
15. DISM Repair - DISM /Online /Cleanup-Image /RestoreHealth
